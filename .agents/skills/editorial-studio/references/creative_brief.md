# Creative brief and intake protocol

Ask only for missing information. Use the existing chat context to fill already-known facts.

## Round 1: the brief

- What exactly is being created? Magazine, onepager, visual report, cover, brochure or another publication?
- What is the subject and why does it exist (inspire, inform, sell, document, announce)?
- Who is the audience? Personal, internal stakeholders, investors, clients, travelers, print readers?
- Output: print A4, digital PDF, portrait/landscape, optional web or editable design. Default to A4 PDF only if not specified.

## Round 2: visual taste

- Which visual adjectives, colors, type style, image mood, or brand constraints matter?
- Example URL? If none, accept screenshot, PDF or a publisher name; allow "no reference".
- Should the result be a timeless art book, an intimate photo diary, a bold editorial statement, or something else?

## Round 3: present alternatives (not the completed magazine)

Use the subject and inspected reference (if available) to present two directions with: name, visual rationale, HEX palette, typography, photography/crops, page pattern, what it would look like on the specific project and one risk/tradeoff. Request a choice or a mix.

Do **not** skip this stage by assuming a style merely because a URL was supplied. When a user explicitly requests a style replica, interpret it as inspiration, not exact reproduction of protected branded pages.

## Example, topic-neutral

User: "I need an image-led magazine about European architecture for design-conscious travelers. Minimalist; inspiration: https://example.com."

Respond: "I can take it in two directions: (A) Quiet Atlas — warm paper, thoughtful serif typography and large facade photography; or (B) Frame & Form — crisp contemporary sans-serif, decisive grids and high-contrast architectural crops. Which should be our base?"

Ask for concrete remaining details only when needed; do not send an enormous form for casual exploratory discussion. In the dashboard, a compact two-step brief is appropriate.
